## Descripción

Este proyecto corresponde al Trabajo Práctico Grupal de Aprendizaje de máquina continuación del Trabajo Práctico de Analisis de datos.

El objetivo es realizar un proceso completo de análisis y preparación de datos, desde la exploración inicial del conjunto de datos hasta la construcción y evaluación de modelos de clasificación.

El trabajo utiliza información de denuncias policiales del Departamento de Policía de Nueva York (NYPD), correspondiente al año 2025.

El análisis comprende:

- Exploración y comprensión de los datos (EDA).
- Identificación de errores e inconsistencias.
- Análisis de valores faltantes.
- Evaluación de mecanismos de ausencia (MCAR, MAR y MNAR).
- Detección y análisis de outliers.
- Transformación y preparación de variables.
- Selección de atributos relevantes.
- Tratamiento del desbalance de clases.
- Construcción de modelos de clasificación.
- Optimización de hiperparámetros.
- Evaluación y comparación de modelos.
- Selección del modelo final.

## Dataset

Se utiliza el conjunto de datos:

`NYPD_Complaint_Data_Current_(Year_To_Date)_20260504.csv`

Para el desarrollo del trabajo se consideran únicamente los registros correspondientes al año 2025.
